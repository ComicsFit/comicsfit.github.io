Ridurre le dimensioni dei CBZ

Le scansioni dei fumetti sono spesso due o tre volte più grandi dello schermo di un e-reader. ComicsFit ridimensiona ogni pagina alla risoluzione esatta del tuo dispositivo e la ricomprime: i file si riducono spesso del 50-90%, senza differenze visibili sul dispositivo.

↓ Scarica per macOS
Come fare

Comprimi i fumetti in cinque passaggi

  1. Scarica ComicsFit per macOS, Windows o Linux e aprilo.
  2. Trascina i tuoi file .cbz, .cbr o .epub nella finestra.
  3. Seleziona il tuo e-reader, o imposta una risoluzione personalizzata per un tablet o uno smartphone.
  4. Scegli un formato di uscita. Se vuoi solo ridurre le dimensioni di un CBZ, seleziona un Kobo o il profilo Personalizzato, poi scegli CBZ.
  5. Fai clic su Converti. ComicsFit mostra quanto spazio hai risparmiato.
Da dove arriva il risparmio

Tre modi per alleggerire i fumetti

  • Adatta le pagine allo schermo Il guadagno maggiore. Una scansione alta 3000 pixel mostrata su uno schermo da 1680 pixel spreca la maggior parte dei suoi pixel. ComicsFit non ingrandisce mai: le pagine più piccole restano come sono.
  • Bianco e nero Su un e-reader in scala di grigi, i dati di colore sono sprecati. La conversione in scala di grigi riduce ancora le dimensioni.
  • Ritaglia i margini Rimuove i margini bianchi per lasciare al disegno tutto lo schermo.
