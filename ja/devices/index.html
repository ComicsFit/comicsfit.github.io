ComicsFit をダウンロード

無料で使えます。4 MB。アカウント不要。

↓ macOS 版をダウンロード ↓ Linux 版をダウンロード ↓ Windows 版（x64）をダウンロード

Windows on ARM をお使いですか？ ARM64 版をダウンロード

macOS（Apple シリコン）· Linux GTK4/Adwaita · Windows 10/11（x64 と ARM64）

Windows では .NET デスクトップ ランタイム 10 以降が必要です。インストールされていない場合は、ComicsFit を開いたときに Windows がダウンロードを提案します。

⚠️ macOS のセキュリティ警告: ComicsFit はまだ Apple の公証を受けていません。初回起動時は、アプリを右クリック → 開く を選び、ダイアログで 開く をクリックしてください。macOS にブロックされた場合は、システム設定 → プライバシーとセキュリティ で 「このまま開く」 をクリックします。この操作は 1 回だけで済みます。
