Kindle でマンガを右から左に読む

マンガは右から左に読みますが、変換したファイルの多くは Kindle で左から右に開いてしまいます。ComicsFit でマンガモードをオンにして AZW3 に変換すれば、本来の向きでページをめくれます。

↓ macOS 版をダウンロード
使い方

5 ステップでマンガを Kindle に

  1. macOS、Windows、Linux 用の ComicsFit をダウンロードして開きます。
  2. マンガの各巻（.cbz、.cbr、.epub）をウインドウにドロップします。
  3. デバイスリストでお使いの Kindle を選びます。
  4. AZW3 のまま、マンガモードをオンにします。白黒の Kindle なら白黒もオンにしましょう。マンガの多くはもともとグレースケールなので、ファイルが小さくなります。
  5. 変換をクリックします。ライセンスがあれば、シリーズ全巻をまとめてキューに入れられます。
ヒント

マンガを正しく表示するために

  • 余白をトリミング スキャン画像には広い白い余白があることがよくあります。トリミングすると、6〜7 インチの画面で絵が大きくなります。
  • 見開きページ 横長の見開きページは分割せずに残し、Kindle を横向きにしたときに画面いっぱいになるサイズにします。
  • ファイルサイズを小さく ページを Kindle の解像度に合わせてリサイズするため、200 MB のファイルが数分の一になることも多く、ページめくりも速くなります。

転送

Kindle に転送する

  1. Kindle を USB ケーブルでパソコンに接続します。
  2. .azw3 ファイルを Kindle の documents フォルダーにコピーします。
  3. Kindle を取り出します。コミックがライブラリに表示されます。

「Send to Kindle」は AZW3 ファイルに対応していないので、USB ケーブルを使ってください。macOS では、最近の Kindle の一部がドライブとして表示されません。OpenMTP などの無料ツールを使えばファイルをコピーできます。

Windows on ARM をお使いですか？ ARM64 版をダウンロード

macOS（Apple シリコン）· Linux GTK4/Adwaita · Windows 10/11（x64 と ARM64）

Windows では .NET デスクトップ ランタイム 10 以降が必要です。インストールされていない場合は、ComicsFit を開いたときに Windows がダウンロードを提案します。

⚠️ macOS のセキュリティ警告: ComicsFit はまだ Apple の公証を受けていません。初回起動時は、アプリを右クリック → 開く を選び、ダイアログで 開く をクリックしてください。macOS にブロックされた場合は、システム設定 → プライバシーとセキュリティ で 「このまま開く」 をクリックします。この操作は 1 回だけで済みます。
