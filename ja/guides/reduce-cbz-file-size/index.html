CBZ のファイルサイズを小さくする

コミックのスキャン画像は、電子書籍リーダーの画面より 2〜3 倍大きいことがよくあります。ComicsFit は各ページをデバイスの解像度にぴったり合わせてリサイズし、再圧縮します。ファイルサイズは 50〜90% 小さくなることが多く、デバイス上での見た目は変わりません。

↓ macOS 版をダウンロード
使い方

5 ステップでコミックを圧縮

  1. macOS、Windows、Linux 用の ComicsFit をダウンロードして開きます。
  2. .cbz、.cbr、.epub ファイルをウインドウにドロップします。
  3. 電子書籍リーダーを選ぶか、タブレットやスマートフォン用にカスタム解像度を設定します。
  4. 出力形式を選びます。CBZ のサイズを小さくしたい場合は、デバイスで Kobo または「カスタム」を選び、出力形式を CBZ にします。
  5. 変換をクリックします。削減できた容量が ComicsFit に表示されます。
容量を減らせる理由

コミックを小さくする 3 つの方法

  • 画面に合わせてリサイズ 最も効果が大きいのがこれです。高さ 3000 ピクセルのスキャン画像を 1680 ピクセルの画面に表示すると、ピクセルのほとんどが無駄になります。ComicsFit は拡大は一切しないので、小さなページはそのままです。
  • 白黒 グレースケールの電子書籍リーダーでは、色の情報は無駄になります。グレースケールに変換すれば、さらに小さくなります。
  • 余白をトリミング 白い余白を取り除き、絵を画面いっぱいに表示します。
