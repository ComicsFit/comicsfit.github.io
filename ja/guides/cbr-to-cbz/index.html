CBR を CBZ に変換

CBR のコミックは RAR アーカイブで、多くのアプリや電子書籍リーダーでは開けません。CBZ は同じものを ZIP にした形式で、ほぼどこでも開けます。ComicsFit は CBR を CBZ に変換し、その際にページのリサイズや圧縮もできます。

↓ macOS 版をダウンロード
使い方

5 ステップで CBR を CBZ に

  1. macOS、Windows、Linux 用の ComicsFit をダウンロードして開きます。RAR に標準対応しているので、ほかに何もインストールする必要はありません。
  2. .cbr ファイルをウインドウにドロップします。
  3. お使いの Kobo、またはカスタムを選び、タブレット、スマートフォン、リーダーアプリの解像度を入力します。
  4. 出力形式に CBZ を選びます。
  5. 変換をクリックします。
より適した形式

電子書籍リーダーで読むなら

CBZ は最も互換性の高いコミック形式ですが、どのデバイスにも最適とは限りません。Kindle なら AZW3 に変換しましょう。Kindle は CBZ をまったく開けません。Kobo なら KEPUB のほうがページめくりが速くなります。reMarkable なら PDF を使いましょう。どの場合も ComicsFit は CBR を直接読み込めます。

macOS（Apple シリコン）· Linux GTK4/Adwaita · Windows 10/11（x64 と ARM64）

Windows では .NET デスクトップ ランタイム 10 以降が必要です。インストールされていない場合は、ComicsFit を開いたときに Windows がダウンロードを提案します。

⚠️ macOS のセキュリティ警告: ComicsFit はまだ Apple の公証を受けていません。初回起動時は、アプリを右クリック → 開く を選び、ダイアログで 開く をクリックしてください。macOS にブロックされた場合は、システム設定 → プライバシーとセキュリティ で 「このまま開く」 をクリックします。この操作は 1 回だけで済みます。
