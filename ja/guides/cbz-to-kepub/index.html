Kobo 向けに CBZ・CBR を KEPUB に変換

Kobo の電子書籍リーダーは CBZ や EPUB を開けますが、ページめくりが遅くなります。KEPUB は Kobo 独自の読書エンジンを使うので、ページめくりが速く、マンガを右から左に読めます。ComicsFit はお使いの Kobo に合わせたサイズの KEPUB に変換します。

↓ macOS 版をダウンロード
使い方

5 ステップで CBZ を KEPUB に

  1. macOS、Windows、Linux 用の ComicsFit をダウンロードして開きます。
  2. .cbz、.cbr、.epub、.kepub ファイルをウインドウにドロップします。
  3. デバイスリストでお使いの Kobo を選びます。解像度は自動で設定されます。
  4. 出力形式は KEPUB のままにします。白黒の Kobo なら、ファイルを小さくするために白黒をオンにします。Kobo Libra Colour や Clara Colour ではオフのままにします。
  5. 変換をクリックします。
KEPUB を選ぶ理由

Kobo での KEPUB と CBZ・EPUB の違い

CBZ と通常の EPUB は Kobo の古いリーダーで開かれ、大きな画像ではかなり遅くなります。KEPUB は Kobo ストアの本と同じエンジンで開かれます。ページめくりが速くなり、読書の統計が取れ、マンガの右から左のページ順にも対応します。Kobo が認識できるよう、ファイルの拡張子は .kepub.epub のままにします。

マンガを読みますか？ Kobo でマンガを右から左に読む方法をご覧ください。

転送

Kobo に転送する

  1. Kobo を USB ケーブルでパソコンに接続し、電子書籍リーダー側で「接続」をタップします。
  2. .kepub.epub ファイルを KOBOeReader ドライブの好きな場所にコピーします。
  3. ドライブを取り出します。コミックが「マイブック」に表示されます。

ComicsFit が付ける .kepub.epub という拡張子は変えないでください。Kobo はこれを見て KEPUB エンジンを使います。EPUB や CBZ が良ければ、Kobo はそれらにも対応しています。
