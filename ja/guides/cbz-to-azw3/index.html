Kindle 向けに CBZ を AZW3 に変換

Kindle は CBZ や CBR のコミックを開けません。必要なのは、固定レイアウトの本のための Amazon の形式 AZW3 です。ComicsFit は Kindle Previewer や KindleGen なしで、Kindle の画面に合わせたサイズの AZW3 にワンクリックで変換します。

↓ macOS 版をダウンロード
使い方

5 ステップで CBZ を AZW3 に

  1. macOS、Windows、Linux 用の ComicsFit をダウンロードして開きます。
  2. .cbz、.cbr、.epub ファイルをウインドウにドロップします。
  3. デバイスリストでお使いの Kindle を選びます。解像度は自動で設定されます。
  4. 出力形式は AZW3 のままにします。右から左に読む本ならマンガモードを、グレースケールの Kindle ならファイルを小さくするために白黒をオンにします。
  5. 変換をクリックします。
KindleGen 不要

Kindle Previewer が不要な理由

Kindle Comic Converter をはじめ、ほとんどのコミック変換ツールは最後の工程を Amazon の KindleGen に任せています。Amazon はもう KindleGen を単体で提供しておらず、約 1 GB の Kindle Previewer に同梱されているだけです。ComicsFit は独自の AZW3（KF8）書き出し機能を持っているので、変換のすべてが 4 MB のアプリひとつで完結します。

KCC をお使いですか？ ComicsFit との違いをご覧ください。

AZW3 を選ぶ理由

Kindle での AZW3 と MOBI・PDF の違い

AZW3 は各ページを全画面で表示し、素早いページめくりとマンガの右から左への読み進め方に対応しています。MOBI は AZW3 に置き換えられた旧形式です。PDF も Kindle で開けますが、ページに余白が付き、小さく表示されます。大画面の Kindle Scribe は例外で、ComicsFit でも PDF を選べます。

転送

Kindle に転送する

  1. Kindle を USB ケーブルでパソコンに接続します。
  2. .azw3 ファイルを Kindle の documents フォルダーにコピーします。
  3. Kindle を取り出します。コミックがライブラリに表示されます。

「Send to Kindle」は AZW3 ファイルに対応していないので、USB ケーブルを使ってください。macOS では、最近の Kindle の一部がドライブとして表示されません。OpenMTP などの無料ツールを使えばファイルをコピーできます。

macOS（Apple シリコン）· Linux GTK4/Adwaita · Windows 10/11（x64 と ARM64）
