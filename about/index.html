About ComicsFit

Hi, I'm Brice, the developer behind ComicsFit.

Why I built it

I love reading manga on my Kobo Libra Colour. When I looked for software to optimize my comics and manga, the tools I found were too big, and I couldn't find one with a native version for each desktop platform: macOS, Windows and Linux.

I wanted a small, native app that could use all my CPU cores to get through conversions as fast as possible. That's why I built ComicsFit.

Get in touch

Found a bug or have a feature request? Open an issue on GitHub so I can track it. GitHub issues are public.

For license questions or anything private, email me at brice.p.thomas+comicsfit@gmail.com.
