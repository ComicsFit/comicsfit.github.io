CBZ-Dateien verkleinern

Comic-Scans sind oft zwei- bis dreimal größer als der Bildschirm eines E-Readers. ComicsFit verkleinert jede Seite auf die genaue Auflösung deines Geräts und komprimiert sie neu: Dateien werden oft um 50 bis 90 % kleiner, ohne sichtbaren Unterschied auf dem Gerät.

↓ Für macOS herunterladen
Anleitung

Comics in fünf Schritten komprimieren

  1. Lade ComicsFit für macOS, Windows oder Linux herunter und öffne es.
  2. Lege deine .cbz-, .cbr- oder .epub-Dateien im Fenster ab.
  3. Wähle deinen E-Reader oder gib eine eigene Auflösung für ein Tablet oder Smartphone ein.
  4. Wähle ein Ausgabeformat. Wenn du nur eine CBZ-Datei verkleinern möchtest, wähle einen Kobo oder das Profil Benutzerdefiniert und anschließend CBZ.
  5. Klicke auf Konvertieren. ComicsFit zeigt an, wie viel Platz du gespart hast.
Woher die Ersparnis kommt

Drei Wege zu kleineren Comics

  • Auf den Bildschirm verkleinern Der größte Gewinn. Ein 3000 Pixel hoher Scan auf einem 1680 Pixel hohen Bildschirm verschwendet die meisten seiner Pixel. ComicsFit skaliert nie hoch: Kleinere Seiten bleiben, wie sie sind.
  • Schwarz-Weiß Auf einem Graustufen-E-Reader sind Farbdaten verschwendet. Die Umwandlung in Graustufen verringert die Größe weiter.
  • Ränder beschneiden Entfernt weiße Ränder, damit das Bild den ganzen Bildschirm ausfüllt.

Windows braucht die .NET Desktop Runtime 10 oder neuer. Fehlt sie, bietet Windows beim Öffnen von ComicsFit an, sie herunterzuladen.
