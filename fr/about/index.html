À propos de ComicsFit

Bonjour, je suis Brice, le développeur de ComicsFit.

Pourquoi je l’ai créé

J’adore lire des mangas sur ma Kobo Libra Colour. Quand j’ai cherché un logiciel pour optimiser mes BD et mangas, les outils que j’ai trouvés étaient trop lourds, et aucun n’avait de version native pour chaque système de bureau : macOS, Windows et Linux.

Je voulais une petite application native, capable d’utiliser tous les cœurs de mon processeur pour convertir le plus vite possible. C’est pour ça que j’ai créé ComicsFit.

Me contacter

Un bug ou une idée de fonctionnalité ? Ouvrez un ticket sur GitHub pour que je puisse le suivre. Les tickets GitHub sont publics.

Pour les questions de licence ou les demandes privées, écrivez-moi à brice.p.thomas+comicsfit@gmail.com.
